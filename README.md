## Featured work

### [Finding quantum error-correction thresholds](https://github.com/ayomikun-adekeye/finding-qecc-thresholds)

A Monte Carlo study of rotated and unrotated surface-code memories under phenomenological noise. The project uses **Stim**, **Sinter**, and **PyMatching** to compare logical error rates across code distances and identify threshold regions.
